# Datenleiche

Datensatz, auf den nichts mehr zeigt oder der auf etwas Gelöschtes zeigt (z. B. ein Dokument zu einem gelöschten Berater). Unbenutzte Profil-Elemente oder eigene Skills sind keine Datenleichen, sondern gültige Einträge; das Housekeeping führt sie in der eigenen Rubrik *Unbenutzt* (#288).
