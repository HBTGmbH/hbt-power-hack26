# Alias

Weiterer Name eines Skills im Skill-Baum (z. B. `JS` für `JavaScript`), global eindeutig ohne Groß-/Kleinschreibung, oder eines Profil-Elements, dort innerhalb des Typs eindeutig. Wer ihn tippt, bekommt den Skill bzw. das Element. Bei Profil-Elementen ist ein Alias ein [Früherer Name](<Früherer Name.md>), auch wenn ein Admin ihn von Hand angelegt hat (#270).
